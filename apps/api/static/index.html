How an answer is built

Five stages. Each one can refuse, and a refusal is a real answer.

1

Availability

The registry decides. Nothing downstream runs for a subject it has not cleared.

2

Retrieval

Lexical and semantic in one SQL query, fused with RRF at k=60.

3

Reranking

A cross-encoder scores the fused pool; source priority is a feature, not a filter.

4

Generation

One model, gemma4:e4b. No silent substitution when it is unavailable.

5

Validation

A citation that does not resolve to this turn's context is stripped.
